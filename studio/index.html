Hamilton-Jacobi-Isaacs formulation (background; this page does not run an HJ solver)

Safety in falsesafe-bench is mathematically defined via viscosity solutions to the Hamilton-Jacobi-Isaacs PDE over state space 𝒳:

∂_t V(t, x) + min_{u ∈ 𝒰} max_{d ∈ 𝒟} ∇V(t, x) · f(x, u, d) = 0,   V(0, x) = l(x)

When dynamics f(x, u) are learned from data, unvisited coverage gaps induce epistemic variance σep(x). We expand the disturbance set dynamically:

𝒟(x) = 𝒟_{al} ⊕ { d ∈ ℝ^n : ||d||_2 ≤ k · σ_{ep}(x) }

Separated vs Blended Uncertainty (Hypothesis H4): In higher dimensions (3D Dubins Car), separated uncertainty kepσep + σal provably avoids over-conservatism compared to vector-norm blending √((k·σep)² + σal²).
